**StatEase** is a browser-based statistical and research analytics platform designed to make statistical analysis, research workflows, and academic reporting more accessible.

Developed under **Salek Data Lab**, StatEase brings essential statistical tools and research utilities into one platform, with a focus on practical research applications, methodological transparency, and accessibility.

🌐 **Live Application:** https://statease-research-analytics.vercel.app/

---

## Key Features

- **Data Management:** Import and manage research datasets.
- **Statistical Analysis:** Descriptive statistics, hypothesis testing, and correlation analysis.
- **Exploratory Data Analysis:** Data exploration and graphical visualization.
- **Research Utilities:** Sample size calculation and literature matrix.
- **Academic Reporting:** APA 7 table generation and bilingual interpretation.
- **Validation:** Statistical validation dashboard.
- **User Experience:** Dark and light themes.

## Methodological Transparency

StatEase distinguishes between implemented browser-side functionality and methods requiring additional computational infrastructure.

**Status definitions:**

- **Functional · Self-Tested:** Implemented and tested by the developer.
- **Functional · Not Fully Validated:** Implemented, but further independent statistical validation is needed.
- **Backend Required:** Requires additional backend or R/Python computational infrastructure; no analytical results are currently generated.
- **Planned:** Not yet implemented.

> Statistical outputs should be independently verified before being used in academic publications, theses, or scientific reports. StatEase is a research utility, not a substitute for methodological review or statistical expertise.

## Technology & Architecture

StatEase is designed around browser-side statistical computation, allowing supported analyses to run directly within the user's browser.

- Browser-based interface
- Client-side data processing for supported modules
- No backend-generated statistical results for modules marked Backend Required
- Dark and light interface modes
- Web deployment through Vercel
